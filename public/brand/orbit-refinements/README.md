# Orbit Datum refinements

Three deterministic developments of the selected Orbit Datum direction:

- `co-roc-orbit-a-axial.svg` — the most balanced and closest to the original.
- `co-roc-orbit-b-concentric.svg` — a more technical, layered configuration mark.
- `co-roc-orbit-c-datum-node.svg` — a conservative engineering datum treatment.

All files are transparent 600 × 160 native SVGs using `#171719`, `#d1253c` and neutral grey. They contain no raster assets, filters, gradients or external resources.
