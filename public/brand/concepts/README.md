# Co-Roc logo concepts

Five deterministic SVG logo directions. These files contain only editable SVG markup and native vector geometry; they do not use generated imagery, embedded bitmaps, gradients, filters or external assets.

1. `co-roc-01-orbit-datum.svg` — balanced product mark; trajectory plus engineering datum.
2. `co-roc-02-section-mark.svg` — aerospace section and controlled interface.
3. `co-roc-03-controlled-monogram.svg` — compact technical CR monogram.
4. `co-roc-04-trace-line.svg` — configuration history and traceability.
5. `co-roc-05-linked-release.svg` — collaboration, approval and release.

Open `index.html` to compare the five options. Each SVG uses a transparent background and a restrained `#171719` / `#d1253c` palette.
